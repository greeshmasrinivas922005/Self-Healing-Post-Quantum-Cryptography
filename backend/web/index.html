METHODOLOGY
How to read it

                    
Each value is the average elapsed time per complete operation group over three rounds. Results vary with processor load, JDK version, and hardware.

                    
For a report, repeat the experiment, record the machine and JDK, and compare distributions rather than treating one run as a universal result.
