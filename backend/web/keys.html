LOCAL KEY-BUNDLE ENCRYPTION

Change vault passphrase

This re-encrypts the PQC private-key bundle with a new passphrase. It does not re-encrypt file packages. Minimum length is 10 characters; forgetting the new passphrase is unrecoverable.

The new phrase is sent only to the local Java process and is not logged.

Key handling boundary

The encrypted bundle is stored locally using PBKDF2-HMAC-SHA-256 and AES-GCM. This is not a hardware security module or enterprise KMS.
